# Infotecs C++ intern test task

Тестовое задание состоит из динамической библиотеки и двух программ,
взаимодействующих через UDP-сокеты.

## Структура проекта

- `lib` — динамическая библиотека обработки данных;
- `app_1` — двухпоточный клиент;
- `app_2` — UDP-сервер;
- `tests` — unit-тесты функций библиотеки на GoogleTest.

## Библиотека

Библиотека `data_parser` предоставляет три функции:

- `sortAndReplaceEvenDigits()` сортирует строку по убыванию и заменяет чётные
  цифры на `KB`;
- `calculateDigitSum()` возвращает сумму цифр, оставшихся в обработанной строке;
- `isValidSum()` проверяет, что сумма содержит не меньше трёх цифр и кратна 32.

## Требования

- Linux;
- компилятор GCC с поддержкой C++17;
- CMake 3.16 или новее;
- Git и доступ к интернету для первой загрузки GoogleTest.

## Сборка

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
cmake --build build
```

Запуск тестов:

```bash
cd build
ctest --output-on-failure
cd ..
```

## Сборка без тестов

Если тесты не нужны или нет доступа к интернету:

```bash
cmake -S . -B build-no-tests \
    -DCMAKE_BUILD_TYPE=Release \
    -DBUILD_TESTING=OFF

cmake --build build-no-tests
```

## Запуск

Сначала запустите сервер:

```bash
./build/app_2/server
```

По умолчанию сервер использует UDP-порт `1337`. Другой порт можно передать
первым аргументом:

```bash
./build/app_2/server 5000
```

Во втором терминале запустите клиент:

```bash
./build/app_1/client
```

По умолчанию клиент отправляет данные на `127.0.0.1:1337`. Адрес и порт можно
указать явно:

```bash
./build/app_1/client 127.0.0.1 5000
```

После запуска клиента введите строки длиной от 1 до 64 символов, состоящие
только из цифр. Для корректного завершения клиента нажмите `Ctrl+D` на пустой
строке.
